Local-first notes for macOS

Your notes live here. Nowhere else.

NotebookThis Mac Tags# local-first# offline

NODI is a quiet, native notes app for the Mac. Rich text, notebooks, tags, instant search and on-device voice dictation, all stored in one SQLite file on your disk. No account, no cloud, no sync server.

What NODI makes of your input

Two small examples of what happens to what you give NODI.

Spoken sentence → checklist

Dictate a list out loud and NODI recognizes it: the transcript is inserted as real checklist items, not a run-on sentence.

You say

“Make a to-do list: call the printer, review the contract and send the invoice”

→
NODI writes
  • call the printer
  • review the contract
  • send the invoice

List commands are recognized in Portuguese and English (“crie uma lista…”, “make a list…”). Anything else is inserted as plain dictated text.

Light ↔ dark

The same note in both themes. Drag the handle, or focus it and use the arrow keys: light on the left, dark on the right.

Privacy

What NODI never does

There is no backend to trust, because there is no backend.

  • Ask you to create an account
  • Upload your notes to a server
  • Send your voice to the cloud for transcription
  • Track what you write
Everything lives in one file you can back up yourself: ~/Library/Application Support/com.nodi.app/nodi.db

Install

Build NODI on your Mac

NODI is built from source for now. You need Node.js, pnpm, Rust, the Xcode Command Line Tools and CMake.

  1. Install dependencies with pnpm.
  2. Build the app. Tauri produces a .dmg in src-tauri/target/release/bundle/dmg/.
  3. Open the .dmg and drag NODI into Applications.
zsh
# check your toolchain
$ node --version && pnpm --version && cargo --version && cmake --version

# install and build
$ pnpm install
$ pnpm tauri build
