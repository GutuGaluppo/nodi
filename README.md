# NODI

Local-first notes for macOS, built with Tauri 2, React, TypeScript, and Vite.

## Development

```bash
pnpm install
pnpm tauri dev
```

## Installation and updates

See the Portuguese guide for [installing and updating NODI](docs/INSTALACAO_E_ATUALIZACAO.md) on macOS.
